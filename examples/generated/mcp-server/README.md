# todo MCP server

Generated by [tracekit](https://github.com/hesselb20-ctrl/tracekit) from a recorded session.
7 tools over `http://localhost:4010`.

## Run

```bash
npm install
node index.js
```

The server speaks MCP over stdio.

## Add to Claude Code

```bash
claude mcp add todo -- node /absolute/path/to/mcp-server/index.js
```

Or in `.mcp.json`:

```json
{
  "mcpServers": {
    "todo": {
      "command": "node",
      "args": [
        "/absolute/path/to/mcp-server/index.js"
      ],
      "env": {
        "TODO_BASE_URL": "http://localhost:4010"
      }
    }
  }
}
```

## Environment

| Variable | Purpose |
|---|---|
| `TODO_BASE_URL` | API base URL. Defaults to `http://localhost:4010`. |
| `TODO_TOKEN` | Bearer token for authenticated calls. Optional: the `login` tool can obtain it instead. |
| `TODO_TIMEOUT_MS` | Per-request timeout. Defaults to 30000. |

Credentials stay inside the server process. When a login tool returns a token, the server keeps it
and replaces it in the tool result, so it never enters the model's context.

## Tools

| Tool | Request | Description |
|---|---|---|
| `login` | `POST /api/login` | Login (POST /api/login). Body fields: email, password. Returns the credential that the other operations need, so call it first. |
| `get_me` | `GET /api/me` | Get me (GET /api/me). Requires a bearer token from login. |
| `list_todos` | `GET /api/todos` | List todos (GET /api/todos). Query parameters: done (optional). Requires a bearer token from login. |
| `get_todo` | `GET /api/todos/{id}` | Get todo (GET /api/todos/{id}). Use the id returned by list_todos or create_todo. Requires a bearer token from login. |
| `create_todo` | `POST /api/todos` | Create todo (POST /api/todos). Body fields: title. Requires a bearer token from login. |
| `update_todo` | `PATCH /api/todos/{id}` | Update todo (PATCH /api/todos/{id}). Use the id returned by list_todos or create_todo. Body fields: done (optional), title (optional). Requires a bearer token from login. |
| `delete_todo` | `DELETE /api/todos/{id}` | Delete todo (DELETE /api/todos/{id}). Use the id returned by list_todos or create_todo. Requires a bearer token from login. |

Only use this server against applications you own or whose terms allow automated access.
